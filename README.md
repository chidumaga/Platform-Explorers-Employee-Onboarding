# Employee Onboarding Tracker
**Contoso HR | Power Platform Solution**
 
---
 
## Overview
 
Contoso HR onboards 30+ employees monthly. IT setup, equipment issue and access provisioning were previously tracked in spreadsheets, causing tasks to fall through the cracks and new starters arriving without access on Day 1.
 
This solution replaces those spreadsheets with a structured, automated onboarding system built entirely on the Microsoft Power Platform.
 
---
 
## What it does
 
- Auto-generates a task checklist the moment a new employee record is created
- Routes IT equipment and system access requests through structured approval workflows
- Sends Teams and email notifications at every stage — assignment, reminders, escalations and completion
- Escalates overdue tasks automatically to the relevant manager before the start date
- Provides real-time dashboards for HR, IT and leadership
